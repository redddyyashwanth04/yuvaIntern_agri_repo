# Week 2 — Data Cleaning and Preprocessing Strategy

**Focus area:** A preprocessing strategy for agricultural mandi price & arrivals data,
structured around the real field schema of Agmarknet (Government of India's official
mandi price and arrivals portal).

## Contents

- `Week2_DataCleaning_PreprocessingStrategy.docx` — Full report: reference dataset,
  literature review, common data issues, a six-stage cleaning/preprocessing workflow
  (profiling, missing-data handling, outlier detection, normalization, format
  transformation, validation) with rationale, a pipeline diagram, and a worked
  before/after example.

## Notes

- Uses hypothetical, generic example records (per the task brief) that mirror
  Agmarknet's real fields (state, district, market, commodity, price, arrival date) —
  no live data was downloaded or analyzed.
- Builds on the [Week 1](../Week1) post-harvest loss focus for continuity.
- Non-technical task — no GitHub project URL required for the submission form.
